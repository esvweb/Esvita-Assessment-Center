# Case photos

These are **placeholders**. Each patient profile in `src/lib/personas.ts` lists the
photos it sends when the candidate asks for them, by path.

To use real case photos:

1. Drop the images into the matching folder, e.g. `public/cases/margaret/`.
2. Update the `photos` array for that profile in `src/lib/personas.ts` so the
   `url` and `caption` match the new files.

Use consented, de-identified clinical photography only. Do not commit anything
that could identify a real patient.
